# Login Dashboard System

A simple PHP login and registration system with:

- User registration
- Secure login (password_hash)
- Session-based authentication
- Dashboard page
- Logout system

## Tech Stack
- PHP (MySQLi for database interaction)
- MySQL
- HTML/CSS

> Note: This project uses MySQLi. Future projects will demonstrate PDO for cross-database flexibility.

## Features
- Input validation
- Prepared statements (SQL injection protection)
- Password hashing
